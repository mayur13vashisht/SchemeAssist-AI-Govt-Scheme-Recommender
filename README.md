# SchemeAssist AI – Government Scheme Recommendation System

## Project Overview
SchemeAssist AI is an intelligent, AI-driven government scheme recommendation platform developed under the CivoraX Internship Program by Civora Nexus Pvt. Ltd.

The system analyzes citizen profiles (income, location, category, age, and needs) and matches them with relevant central, state, and local government schemes using explainable AI logic and machine learning-based ranking.

## Key Features
- AI-based eligibility scoring (0–100)
- Personalized scheme recommendations
- Explainable recommendation logic
- Scheme ranking and prioritization
- Deadline-based alerts
- Citizen-friendly dashboard

## Tech Stack
- Backend: Python, Flask
- AI/ML: Pandas, Scikit-learn
- Database: Simulated (can be extended to MongoDB/PostgreSQL)
- Frontend: HTML, CSS, JavaScript
- Version Control: Git & GitHub

## AI Recommendation Logic
The recommendation engine uses a hybrid approach:
- Rule-based eligibility validation
- ML-based ranking and prioritization

Eligibility score is calculated using:
- Income eligibility (30%)
- State/location match (25%)
- Category match (20%)
- Age criteria (15%)
- Deadline urgency (10%)
